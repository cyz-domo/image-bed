1. 根因修复
   - OAuth 回调获取 GitHub 用户资料时，将官方 `avatar_url` 写入签名 session；不再丢弃该字段。
   - `/api/auth/me` 返回 session 中保存的官方头像地址，兼容旧 session 缺少该字段的情况。
   - 头像地址只接受 HTTPS，异常或缺失时由前端首字母 SVG 回退。

2. 前端兼容
   - 保持现有头像加载失败回退逻辑。
   - 登录提示缓存继续覆盖头像 URL，认证确认后更新为最新官方 URL。
   - 不再请求错误的 `https://github.com/<login>.png` 地址。

   - 真实站点问题仅处理 GitHub 头像源。
